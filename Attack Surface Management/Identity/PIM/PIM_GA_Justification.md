# Global Administrator PIM Activations

## Description

This query identifies Microsoft Entra ID Privileged Identity Management (PIM) activations of the Global Administrator role within the last 30 days.

The query analyzes AuditLogs Role Management events generated by PIM and extracts activation details from both the TargetResources and AdditionalDetails fields. Nested JSON objects are expanded into individual columns, making the results easier to search, filter, and investigate.

## Data Sources

* AuditLogs

## Lookback Period

* 30 days

## Included Operations

The query includes the following PIM-related role activation events:

* Add member to role completed
* Activate eligible assignment
* Add member to role requested

## Extracted Information

### Activation Information

* Activation timestamp
* Operation name
* Result status
* Audit type
* Activation request ID

### User Information

* User who activated the role
* Source IP address
* User agent
* Account type
* MFA status

### Role Information

* Role name
* Role definition ID
* Template ID
* PIM assignment request ID

### Approval Information

* Activation justification
* Whether MFA was used
* Whether approval was required

### Directory Information

* Directory name
* Directory ID
* Tenant ID

## Filtering

The query only returns activations where the role name equals:

* Global Administrator

## Investigation Use Cases

This query can be used to:

* Review all Global Administrator activations performed through PIM.
* Validate business justifications for privileged access.
* Verify whether MFA was used during activation.
* Identify the source IP address and browser used.
* Investigate unusual or unauthorized privileged access activity.
* Audit temporary administrative access assignments.
* Support security reviews and privileged access governance assessments.

## Output Columns

| Column                      | Description                             |
| --------------------------- | --------------------------------------- |
| TimeGenerated               | Time of the activation event            |
| OperationName               | PIM operation performed                 |
| Result                      | Operation result                        |
| ActivatedBy                 | User performing the activation          |
| DetailIpAddress             | Source IP address                       |
| TargetGroupName             | Group associated with the activation    |
| Justification               | User-provided reason for activation     |
| StartTime                   | Activation start time                   |
| IsAuthenticatedWithMfa      | Indicates whether MFA was used          |
| IsActivationRequireApproval | Indicates whether approval was required |
| UserAgent                   | Browser or client used                  |
| AuditType                   | PIM audit event type                    |
| RoleAssignmentRequestId     | PIM activation request identifier       |
| RequestId                   | Audit request identifier                |
| ActorObjectId               | Object ID of the activating user        |
| TenantId                    | Tenant identifier                       |
| AccountType                 | Account type                            |
| DirectoryName               | Directory name                          |
| DirectoryId                 | Directory identifier                    |

## Expected Result

Each record represents a single Global Administrator activation request, including the activating user, justification, authentication details, source IP address, and associated PIM metadata.

## KQL

```kql
let lookback = 30d;
AuditLogs
| where TimeGenerated >= ago(lookback)
| where Category =~ "RoleManagement"
| where LoggedByService has_any ("PIM", "Privileged Identity Management")
| where OperationName has_any (
    "Add member to role completed",
    "Activate eligible assignment",
    "Add member to role requested"
)
| extend ActivatedBy = tostring(InitiatedBy.user.userPrincipalName)
| extend ActivatedByIp = tostring(InitiatedBy.user.ipAddress)
| extend ActivatedByApp = tostring(InitiatedBy.app.displayName)
| mv-apply TR = TargetResources on (
    summarize
        RoleId = anyif(tostring(TR.id), tostring(TR.type) =~ "Role"),
        RoleName = anyif(tostring(TR.displayName), tostring(TR.type) =~ "Role"),
        TargetUserId = anyif(tostring(TR.id), tostring(TR.type) =~ "User"),
        TargetUser = anyif(tostring(TR.userPrincipalName), tostring(TR.type) =~ "User"),
        TargetUserDisplayName = anyif(tostring(TR.displayName), tostring(TR.type) =~ "User"),
        TargetGroupId = anyif(tostring(TR.id), tostring(TR.type) =~ "Group"),
        TargetGroupName = anyif(tostring(TR.displayName), tostring(TR.type) =~ "Group"),
        DirectoryId = anyif(tostring(TR.id), tostring(TR.type) =~ "Directory"),
        DirectoryName = anyif(tostring(TR.displayName), tostring(TR.type) =~ "Directory"),
        RequestObjectId = anyif(tostring(TR.id), tostring(TR.type) =~ "Request")
)
| mv-apply Detail = AdditionalDetails on (
    summarize
        RoleDefinitionOriginId = anyif(tostring(Detail.value), tostring(Detail.key) =~ "RoleDefinitionOriginId"),
        RoleDefinitionOriginType = anyif(tostring(Detail.value), tostring(Detail.key) =~ "RoleDefinitionOriginType"),
        TemplateId = anyif(tostring(Detail.value), tostring(Detail.key) =~ "TemplateId"),
        StartTime = anyif(todatetime(Detail.value), tostring(Detail.key) =~ "StartTime"),
        ExpirationTime = anyif(todatetime(Detail.value), tostring(Detail.key) =~ "ExpirationTime"),
        Justification = anyif(tostring(Detail.value), tostring(Detail.key) =~ "Justification"),
        UserAgent = anyif(tostring(Detail.value), tostring(Detail.key) =~ "UserAgent"),
        ResourceOriginId = anyif(tostring(Detail.value), tostring(Detail.key) =~ "ResourceOriginId"),
        AuditType = anyif(tostring(Detail.value), tostring(Detail.key) =~ "AuditType"),
        IsAuthenticatedWithMfa = anyif(tobool(Detail.value), tostring(Detail.key) =~ "IsAuthenticatedWithMfa"),
        IsActivationRequireApproval = anyif(tobool(Detail.value), tostring(Detail.key) =~ "IsActivationRequireApproval"),
        RoleAssignmentRequestId = anyif(tostring(Detail.value), tostring(Detail.key) =~ "RoleAssignmentRequestId"),
        ActorObjectId = anyif(tostring(Detail.value), tostring(Detail.key) =~ "oid"),
        TenantId = anyif(tostring(Detail.value), tostring(Detail.key) =~ "tid"),
        RoleIds = anyif(tostring(Detail.value), tostring(Detail.key) =~ "wids"),
        DetailIpAddress = anyif(tostring(Detail.value), tostring(Detail.key) =~ "ipaddr"),
        AccountType = anyif(tostring(Detail.value), tostring(Detail.key) =~ "acct"),
        RequestId = anyif(tostring(Detail.value), tostring(Detail.key) =~ "RequestId")
)
| where RoleName =~ "Global Administrator"
| extend ActivationDuration = ExpirationTime - StartTime
| project
    TimeGenerated,
    OperationName,
    Result,
    ActivatedBy,
    DetailIpAddress,
    TargetGroupName,
    Justification,
    StartTime,
    IsAuthenticatedWithMfa,
    IsActivationRequireApproval,
    UserAgent,
    AuditType,
    RoleAssignmentRequestId,
    RequestId,
    ActorObjectId,
    TenantId,
    AccountType,
    DirectoryName,
    DirectoryId
| order by TimeGenerated desc
```
